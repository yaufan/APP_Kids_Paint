# 第 0 階段：線稿轉換原型

驗證整個 APP 風險最大的部分：**照片能不能變成 2.5–5 歲小朋友塗得開心的著色圖**。

![比較圖](results/comparison.jpg)

## 真實風格：開源 AI 線條偵測

第一版用「色塊分區」，雖然不會漏色，但線條是色塊的邊界，**看起來不像原本的照片**。
第二版改用開源的邊緣偵測模型 **DexiNed**（MIT 授權，可以商用），描出照片真正的輪廓：

1. **找主角並去背**：原型用 GrabCut 代替。APP 裡會用手機內建的主體偵測（Android ML Kit、iOS Vision），或讓小朋友 **用手指把東西圈起來**。
2. **自動裁切放大**：主角太小（例如火箭）時，會自動放大讓它填滿畫面。
3. **AI 描輪廓**：DexiNed 找出照片中的線條，例如杯緣、把手、湯匙、貓的眼睛、鼻子、鬍鬚。
4. **整理成著色本線條**：
   - 去掉背景的線（例如木紋）
   - 補起小斷點，去掉太短的雜線
   - 統一成粗細一致、圓滑的線條
   - 外框改用去背的輪廓，**整圈完整不斷**
5. **不漏色**：線條忠於照片，難免有小缺口。所以另外計算「塗色區塊圖」：在缺口處設一條看不見的邊界，油漆桶倒下去就不會漏到外面。

| 細緻度 | 適合 | 線條 |
|---|---|---|
| 簡單 | 2.5–4 歲 | 只留明顯的線，線條粗 |
| 普通 | 4–5 歲 | 多一些細節 |
| 細緻 | 大一點的孩子 | 細節最多，線條較細 |

## 可愛風格：不需要 AI

- 主角簡化成幾個圓滑的色塊（每個區塊都封閉）
- 在最寬敞的區塊放上可愛的臉（眼睛、微笑、腮紅）
- 貼紙風外框
- 背景隨機放星星和愛心

## 目前結果（3 張公開樣本照片）

| 照片 | 真實風格 | 可愛風格 |
|---|---|---|
| 咖啡杯 | **像原圖**：杯子、杯緣、把手、湯匙、盤子都清楚 | 可愛的杯子臉 |
| 貓臉特寫 | **看得出是貓**：眼睛、鼻子、鬍鬚、耳朵都有；頭頂毛紋多了一些線 | 不理想：特寫沒有背景，簡化後看不出是貓 |
| 火箭 | 輪廓清楚，但主角太細長，能塗的地方少 | 可以用 |

- **速度**：在伺服器 CPU 上每張約 2.5–6 秒（Python 原型）。
- **模型大小**：DexiNed 約 47 MB。放進 APP 前要先壓縮（量化），並在中低階 Android 手機上實測；太慢的話，改用同一位作者的輕量模型 TEED（同為 MIT 授權）。

**已知問題**
- 貓頭頂的毛紋線條偏多，對 2.5 歲來說可能太雜。
- 主角被照片邊緣切到時，會出現一條直線。
- 可愛風格對動物特寫還不夠好。

## 下一步：需要真實照片

公開樣本只有 3 張，**需要用小朋友實際會拍的東西來測試**。請準備 10–20 張照片，例如：玩具、絨毛娃娃、水果、花、寵物、車子、餐點、公園的溜滑梯。

- **請避免拍到人臉**
- 傳送方式（任選）：
  - 直接在對話中附上
  - 上傳到 GitHub 的 `prototypes/lineart/photos/` 資料夾

## 自己執行

```bash
pip install -r requirements.txt
python run_samples.py                 # 使用內建樣本，結果輸出到 results/
python run_samples.py 照片資料夾/      # 使用自己的照片
python lineart.py 照片.jpg --detail normal --rect 0.1 0.1 0.9 0.9
python lineart.py 照片.jpg --style cute --rect 0.1 0.1 0.9 0.9
```

- 第一次執行會自動下載 DexiNed 模型到 `models/`。這個資料夾不放進 Git。
- `--rect` 是主角的大概範圍（以照片比例表示：左、上、右、下）；主角填滿畫面時可以省略。
- 在照片資料夾放一個 `samples.json`，可以分別設定每張照片的範圍，以及要不要加可愛臉：

```json
{"dog.jpg": {"rect": [0.1, 0.1, 0.9, 0.95], "face": false}}
```

**來源與授權**
- 樣本照片：scikit-image 內建的公開授權樣本（coffee、chelsea、rocket）。
- 模型：[DexiNed](https://github.com/xavysp/DexiNed)（MIT），從 OpenCV Zoo 下載。
