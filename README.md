# Kids Paint（暫名）

給小朋友的著色 APP（Android／iOS）：
**拍下生活中的東西 → 變成專屬著色圖 → 塗上顏色 → 收進「我的城市地圖」，成為成長回憶。**

## 主要功能
- 拍照轉線稿：**真實風格**（保留原貌的黑線圖框）／**可愛風格**（AI 轉成 Q 版）
- 多種筆刷與顏色，含油漆桶、不出界模式、縮時重播
- 地圖日誌：可愛風格城市地圖，記錄在哪裡畫了什麼
- 作品集快速搜尋：依分類、顏色、日期、地點
- 經家長確認後分享到社群，同時推廣 APP
