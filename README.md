# 畫畫小鎮（暫名，原 Kids Paint）

給 **2.5–5 歲** 小朋友的著色 APP（Android 先行，iOS 隨後），台灣市場：
**拍下生活中的東西 → 變成專屬著色圖 → 塗上顏色 → 收進「我的城市地圖」，成為成長回憶。**

## 主要功能
- 拍照轉線稿：**真實風格**（保留原貌的黑線圖框）／**可愛風格**（圓滑外形＋可愛表情＋貼紙風）
- 幼兒友善畫布：油漆桶、不出界的魔法蠟筆、亮粉、印章，零文字操作
- 地圖日誌：可愛風格城市地圖，記錄在哪裡畫了什麼
- 作品集：分類泡泡、我的最愛
- 經家長確認後分享到 LINE、FB、IG，同時推廣 APP

## 目前狀態
- **第 0 階段（技術驗證）**：
  - 線稿轉換原型：真實、可愛 v1、Q 版 v2 都已試做
  - 還在等真實照片測試
- **第 1 階段（MVP）**：目前版本 **0.16.0**，「畫畫小鎮」介面已做進 APP，第一天可以幫小鎮取名字、選一個動物好朋友，小鎮會跟著時間和節日變化，可以在白紙上隨便畫（魔法畫筆有蠟筆、粗粗筆、點點筆、噴漆、水彩筆、霓虹筆、條紋筆，還有彩虹筆、亮晶晶筆和印章；36 種顏色），小鎮有天氣（晴天、下雨、颳風、彩虹），有音效和背景聲，動物園、海洋館、恐龍樂園、交通車館、植物園、昆蟲館、太空、夜市、極地、糖果館裡住著小朋友畫的角色、車子和植物（每個地方 12 個可以畫）（著色圖照兒童著色本的樣子畫：大眼睛、張嘴笑、大頭正面，車子也有臉；挑角色的卡片是彩色的），角色會看情況說話，商店的架子上擺著小朋友畫的牛奶、胡蘿蔔，客人會來買；每天時間到了會溫和地休息，作品可以存到相簿；可以完整走一次：小鎮地圖 → 拍照 → 魔法變身 → 選風格 → 著色 → 寄到地圖上的地方 → 明信片冊。照片用開源 AI 描線模型 TEED 在手機上轉成著色畫，不用連網。
- 還沒做：家長的「開始之前」說明頁、每日時間上限與晚安畫面、貼紙與亮晶晶等工具、分享、語音。
