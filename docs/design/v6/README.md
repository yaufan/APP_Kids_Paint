# 第二版：浮空小島（2.0.0）

小鎮變成一群浮在天上的小島：每個地方一座島，用吊橋、彩虹橋、繩梯和一座鐵軌橋連起來，從最上面的太空一路到最下面的海。

## 怎麼畫
- `islands.py`：整個世界。
  - 世界是 780 × 1760：手機先看到中間 390 寬、以「家」為中心的一塊，平板看到更多。
  - **小島**：草地的頂面（後面一圈亮邊、前面一道深色的邊）、泥土的側面（兩條地層線、幾顆石頭）、下面一個圓圓的石頭尖底，掛著幾條根和小葉子。
    - 極地是雪、太空是月球的灰紫色（有坑）、糖果島是粉紅糖霜加蛋糕的側面（糖霜往下滴）、海上的三座是沙灘、直接坐在海裡（四周一圈白色浪花）。
  - **房子**沿用第一版小鎮的畫（`docs/design/v3/src/town.py`），拿掉底下的圓角色塊和會懸空的樹，縮放後放在島的頂面。
    - 城市島是新畫的：商店、台北 101 和捷運站；山島：兩座山和纜車；沙灘島：棕櫚樹、陽傘、小水池；公園島重新排過（池塘、溜滑梯、樹）。
  - **還沒寄過的島**（幼兒園、公園、廟、去旅行）：同一座島，房子只畫淡淡的一層，旁邊插一塊木牌。
  - **橋**：吊橋（木板加兩條繩子）、很陡的地方用繩梯、山島和城市島到糖果島是彩虹橋、家到交通車館是鐵軌橋（捷運在上面跑）。
  - **天空**：上面深藍有星星（太空在那裡），越往下越亮，最下面是海和浪；白天有太陽、黃昏、晚上有月亮和滿天星星。
  - **可以戳的東西**：捷運（鐵軌橋）、熱氣球、帆船、鴨子（公園池塘兩隻、海上一隻）、台北 101、5 朵雲。
  - **節日**：燈籠、三角旗、粽子、聖誕燈泡掛在家附近的吊橋下；天燈和氣球飄在小島之間；龍舟在海上；中秋的月亮和兔子；聖誕樹在家的島上。
  - 白天、黃昏、晚上：每張圖都有三個版本，用第一版的 `tint` 換顏色（窗戶、燈籠、月亮在晚上會亮）。
- `render_alpha.js`：把 SVG 轉成透明背景的 PNG（量房子的大小、做預覽）。

## 指令
```
python3 islands.py export                         # 寫進 app/assets/art/islands/ 和 app/lib/features/town/island_layout_data.dart
python3 islands.py preview 輸出.png night christmas   # 整個世界的預覽（時段、節日可以省略）
```
需要 Node.js 和 Playwright（和 v3、v5 一樣）。

## APP 裡
- `app/lib/features/town/town_map.dart`：照 `island_layout_data.dart` 把天空、橋、每座島（還沒寄過的用 `_lot`）、玩具、節日疊起來，再放圖釘、小朋友畫的東西、動物好朋友和咕咕。
- 每座島用自己的節奏上下飄（`islandBob`），島上的東西跟著飄；點一座島：能走進去就走進去，有明信片就打開明信片，還沒寄過就說「去拍照，寄到這裡就會蓋好喔！」。
