# Twemoji 原始圖檔

這裡的 SVG 來自 [Twemoji](https://github.com/jdecked/twemoji)（Twitter/X 與其他貢獻者），圖案以 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) 授權，全文在 `LICENSE-GRAPHICS`。

- 可以商用、可以修改，但要註明出處。APP 的「家長模式 → 開放原始碼授權」裡有列出。
- 我們做的修改：把彩色圖案轉成著色用的黑線白底（`twemoji.py`），有些動物再加上自己畫的部分（`animals.py`，例如獅子的鬃毛、斑馬的條紋）；園區背景直接用彩色圖案當裝飾（`creatures.py`）。
- 只放有用到的檔案。要用新的圖案時，從 `https://raw.githubusercontent.com/jdecked/twemoji/main/assets/svg/<代碼>.svg` 下載到這裡。
