# 角色著色圖：兒童著色本風格（0.11.0 起）

可以走進去的 11 個地方，每個地方 12 個、一共 132 個角色的著色圖（0.12.0 加了商店；0.13.0 加了太空、夜市、極地；0.15.0 每個地方補到 12 個，再加糖果館）。0.10.0 用 AI 畫寫實插圖再描線，線條雜亂，跟市面上的兒童著色本差很多；0.11.0 起照兒童著色本的樣子，一個一個用向量畫出來。

## 兒童著色本長什麼樣子
參考幼兒（2～5 歲）著色本和選購建議，共通的特色：
- **一頁一個大大的主角**，沒有背景，四周留白。
- **粗而平均的黑線**（印出來約 3～5 mm），塗出界也沒關係。
- **大區塊、少細節**：沒有毛、鱗片、陰影這些紋路，小手用整隻手臂塗也塗得進去。
- **可愛（kawaii）的造型**：圓圓胖胖、頭大、大大的黑眼睛（有一點白色反光）、腮紅、微笑。
- 動物、車子、花和水果都很常見，常常也有臉。

## 0.14.0：更像小朋友熟悉的繪本角色
參考市面上幼兒著色 APP 的主題選單（太空、海洋、恐龍、交通工具……）：
- **眼睛更大**（放大 1.75 倍），黑黑亮亮的，一大一小兩個白色反光。
- **張開嘴笑**：D 字形的嘴巴，裡面有粉紅色小舌頭（暴龍還有兩顆小牙）。
- **大頭、小身體、正面看著你**：大象、長頸鹿、獅子、斑馬、5 隻恐龍、海龜、獨角仙、螳螂、海豹都重畫。
- **車子也有臉**：眼睛畫在車窗裡，下面一個笑臉。
- 挑角色的卡片改成**彩色角色放在粉彩色卡片上**（`app/assets/previews/`）。

## 這裡怎麼畫
- `kawaii.py`：共用的畫法和顏色。
  - 外框 9 像素、裡面的線 6 像素（頁面 600×800）。
  - 眼睛：大大的黑色橢圓加一大一小兩個白色反光；腮紅、張開的笑嘴（有小舌頭）、鼻孔。
  - `tube`：一條粗的圓頭帶子（象鼻、脖子、花莖、尾巴）。
  - `mirror`：左右對稱（蝴蝶的翅膀、螃蟹的鉗子）。
  - `scallop`：一圈圓圓的波浪（獅子的鬃毛、三角龍的頸盾、玫瑰）。
- `characters.py`：132 個角色，照地方分段。
  - 每個角色只畫一次、用真的顏色。
  - 著色圖就是把顏色全部換成白色，只留下眼睛的黑色。
  - 所以「著色圖」和「它本來的顏色」永遠一樣。
  - 動物大多正面看著你；魚、車子這些會移動方向的面向右邊。都站在 y≈700 的地上。
- `preview.py 輸出.png [角色...]`：上面彩色、下面著色圖，看起來對不對。
- `export.py [角色...]`：寫進 APP。
  - `app/assets/pages/<角色>.png`：著色圖，灰階。
  - `app/assets/previews/<角色>.png`：彩色、去背、長邊 256 像素，挑角色的卡片用。
  - `colors/<角色>.png`：彩色，示範影片用它幫角色上色。

- `icons.py`：同樣畫法的小圖（0.15.0）。
  - 第一天選的 8 個動物好朋友（大大的頭）。
  - 可以走進去的地方的小圖示：一個代表角色放在圓圓的粉彩色徽章上。
  - `python3 icons.py [預覽.png]` 寫進 `app/assets/art/`；`docs/design/v3/src/export_art.py` 也會用它。

## 改一個角色
1. 在 `characters.py` 改它的函式。
2. `python3 preview.py /tmp/x.png 角色名` 看一下。
3. `python3 export.py 角色名`。
4. 在 `app/` 跑 `flutter test test/artwork_service_test.dart`，確定每一頁都有可以塗的區塊。

需要 Node.js 和 Playwright（`docs/design/v3/src/render_svg.js` 用來把 SVG 轉成 PNG）。
