# 視覺設計：繪本貼紙風 v1

給 2.5–5 歲小朋友：**看起來像一本可以摸的圖畫書**。畫面上沒有文字，每個按鈕都像一張可以按下去的貼紙。

![手機](design/phone.jpg)
![平板橫放](design/tablet.jpg)

## 設計原則
| 原則 | 做法 |
|---|---|
| 按得下去的感覺 | 貼紙按鈕：粗深色外框＋實心陰影。按下時按鈕往下沉，陰影消失 |
| 主要動作最醒目 | 首頁的相機按鈕最大，並且會輕輕「呼吸」（放大縮小）邀請小朋友點 |
| 有角色、有溫度 | 吉祥物「蠟筆寶寶」會眨眼、揮手；首頁是有笑臉太陽、雲朵、山丘的繪本場景 |
| 像真的畫畫用品 | 調色盤是一盒真的蠟筆，選到的那支會跳出來；畫紙是一張有外框的紙 |
| 作品像寶貝 | 作品集像貼在牆上的拍立得照片：每張微微傾斜，貼著紙膠帶 |
| 家長畫面另成一格 | 家長模式用簡潔的卡片，同一套字型與配色，但以文字為主 |

## 設計元素
- **字型**：jf open 粉圓 2.1（justfont，SIL OFL 1.1，可商用）。授權全文在 APP 的「家長模式 → 開放原始碼授權」。
- **配色**（`lib/app/theme.dart` 的 `KidColors`）

| 名稱 | 色碼 | 用途 |
|---|---|---|
| paper 紙 | `#FFF6E5` | 背景 |
| ink 墨 | `#3D2C2E` | 所有外框、陰影 |
| berry 莓果粉 | `#FF6F91` | 主要動作（拍照） |
| sun 向日葵黃 | `#FFC93C` | 回首頁 |
| sky 天空藍 | `#4FB8F5` | 作品、真實風格、油漆桶 |
| grass 草綠 | `#6CCB6A` | 地圖、魔法蠟筆 |
| lavender 薰衣草紫 | `#AE8CF5` | 復原 |
| tangerine 橘子 | `#FF9F45` | 吉祥物 |

- **元件**（`lib/app/`）

| 元件 | 用途 |
|---|---|
| `KidButton` | 貼紙按鈕，有圓形與圓角方形兩種 |
| `StickerCard` | 有外框和陰影的白卡，可以傾斜、貼紙膠帶 |
| `StickerBadge` | 裝飾用的小圓貼紙 |
| `AvatarBadge` | 小朋友的動物頭像 |
| `BouncingDots` | 等待中動畫，用來代替文字 |
| `SceneBackground` | 首頁繪本場景 |
| `PaperBackground` | 其他畫面的點點紙背景 |
| `CrayonBuddy` | 吉祥物 |
| `CrayonTray` | 蠟筆調色盤 |

- **尺寸**：
  - 主要按鈕約為螢幕短邊的 46%（150–260 dp）
  - 工具按鈕 72 dp
  - 外框 4 px、陰影深度 6 px

## 版面
- **手機直向**：工具在上方，畫紙在中間，蠟筆盒在下方（兩排、每排 6 支，不需要滑動）。
- **平板橫向**：工具在左側，畫紙在中間，蠟筆盒在右側（直排一列）。
