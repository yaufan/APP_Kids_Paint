# 視覺設計 v3：畫畫小鎮（完整版）

方向 A「畫畫小鎮」：**主畫面就是小朋友自己的城市地圖**。每張畫完成後變成一張明信片，由郵差鴿「咕咕」寄回地圖，插在拍照的地方。

- 原始碼：`docs/design/v3/src/`（`kit.py` 元件、`screens.py` 每個畫面、`render.js` 輸出截圖）
- 每個畫面的截圖：`docs/design/v3/screens/`（390 × 844，2 倍解析度）
- 手機好看的對照圖：`docs/design/v3/sheets/`

重新產生：
```bash
cd docs/design/v3/src
python3 screens.py      # 產生 html/
node render.js          # 產生 screens/*.png
python3 sheet.py        # 產生 sheets/*.jpg
```

## 和前一版比，哪裡不一樣
| 前一版的問題 | v3 的做法 |
|---|---|
| 畫面空、顏色淡，看起來單調 | 地圖有天空、山、貓空纜車、淡水河與彩虹橋、捷運、101、夜市、廟、公園、動物園；車子、機車、公車、船、鴨子、熱氣球都在動 |
| 沒有角色個性 | 小朋友自己的動物在地圖上走路；新增郵差鴿「咕咕」負責寄明信片 |
| 地圖日誌只是佔位頁 | 地圖就是首頁；作品變成圖釘，今天的作品發光；還沒畫過的地方是虛線的「＋」圖釘，鼓勵去新地方 |
| 最好玩的「照片變著色畫」看不到 | 專屬的「魔法變身」畫面：魔法棒劃過，照片一半變成線稿 |
| 完成後沒有獎勵感 | 「寄出」郵戳、彩帶、咕咕把明信片叼回地圖，右上角的明信片數 +1 |
| 分享沒有設計 | 家長專用的分享卡：預設只放作品、動物頭像、地點種類和日期，加上 APP 標誌 |

## 畫面流程
```
第一次使用：開始之前（給家長）→ 選角色 → 第一天的小鎮（只有家）
小鎮地圖 → 點圖釘 → 地點卡（看這裡的明信片、在這裡再畫一張）
小鎮地圖 → 拍照 → 魔法變身 → 選風格（真實／可愛）→ 著色（＋貼紙）
        → 寄到哪裡？ → 寄出（新地方就蓋好新建築）→ 回到地圖
小鎮地圖 → 明信片冊（依地點分組、最愛）
家長關卡 → 家長模式、隱私與安全、分享
時間到 → 晚安畫面
```
地圖規則見 [town-map.md](town-map.md)，安全設計見 [safety-privacy.md](safety-privacy.md)。

## 每個畫面
1. **小鎮地圖（首頁）**：可以左右上下拖動的大地圖。左上是小朋友的頭像和「小熊的小鎮」，右上是已經寄了幾張明信片、家長鎖。下方是大大的相機鈕（會呼吸），左邊明信片冊、右邊主題著色本。
2. **地點卡**：點地圖上的圖釘，地圖變暗，下方滑出這個地點的明信片（橫向滑動）和「在這裡再畫一張」。
3. **拍照**：全螢幕相機畫面加取景框。小熊在角落用語音說「對準你想畫的東西」。左下是相簿，中間快門，右邊換鏡頭。
4. **魔法變身**：等待轉換時的畫面（約 1～3 秒）。深藍星空背景，小熊揮魔法棒，照片一半已經變成線稿。三顆星星代表進度，不用讀字。
5. **選風格**：兩張明信片，相機徽章是「真實」，星星徽章是「可愛」。點一張就開始畫。
6. **著色**：背景是這個地點放大後的模糊地圖，好像真的坐在公園裡畫。明信片右上角是原本照片做成的郵票，加上日期郵戳。工具是畫出來的小物件：油漆桶、蠟筆、亮晶晶、花紋、貼紙，選中的會跳起來。下面是 12 色顏料，綠色大鈕「畫好了，寄出」。
7. **貼紙**：從下面滑出貼紙本：星星、愛心、花、太陽、彩虹、雲、蝴蝶、火箭，都有表情；上方分類：可愛、動物、交通、我的照片（以後可以把自己的作品變成貼紙）。
8. **寄出**：明信片蓋上「寄出」郵戳，彩帶噴出，咕咕叼著明信片飛回地圖，明信片數 +1。下面兩個鈕：回到小鎮、再畫一張。
9. **明信片冊**：依地點分組（公園、家裡、101⋯），上方可以篩選「全部、最愛、各地點」，每張可以按愛心。
10. **分享（家長）**：在家長鎖後面。預設不顯示名字、不放原照片，地點只說「公園」；照片裡有人臉時會提醒。分享的圖已經拿掉 GPS 和拍攝時間。分享圖右下角有「畫畫小鎮」標誌，順便推廣 APP。
11. **選角色（第一次使用）**：咕咕歡迎小朋友，選 8 隻動物之一，爸媽幫忙打名字和年紀，按「出發」。
12. **家長模式**：小朋友名單（可以多個）、每天可以玩多久（時間到小熊會說晚安）、我們的地方（替公園、阿嬤家取名字）、隱私與安全、開放原始碼授權。
13. **第一天的小鎮**：只有家，其他地方是插著木牌的空地，咕咕說「小鎮還空空的，去拍照把它蓋起來吧！」
14. **寄到哪裡？**：畫好後，咕咕問要寄到哪裡。只放 4 張大卡片（上次的地方有黃框）＋「更多地方」。
15. **蓋好新地方**：第一次寄到公園，鷹架和起重機冒出來，公園長出來，出現「新地方：公園！」。
16. **家長確認**：小熊用語音請小朋友找大人；國字數字題＋大數字鍵盤；答錯 3 次等 1 分鐘。
17. **開始之前（給家長）**：第一次打開時說明怎麼保護小朋友，允許相機，設定每天可以玩多久。
18. **晚安**：時間到了，小熊去睡覺，顯示今天寄出的明信片；家長可以通過關卡再玩 10 分鐘。
19. **隱私與安全**：資料都在這支手機、用到哪些權限、匯出全部明信片、刪除資料。

## 動畫與聲音（規劃）
- 所有按鈕按下會壓扁再彈回，配「啵」的音效。
- 地圖上的車子、捷運、船、纜車、雲會慢慢移動；小朋友的動物會走來走去。
- 今天的圖釘有一圈一圈的光；還沒畫過的地方圖釘輕輕晃動。
- 魔法變身：魔法棒的光從左上劃到右下，配「叮叮叮」。
- 寄出：郵戳「咚」一聲，彩帶，咕咕拍翅膀飛回地圖，圖釘掉下來彈一下。
- 角色語音（國語）：「對準你想畫的東西」「你喜歡哪一張？」「寄出囉！」。

## 設計規範
- **字型**：jf open 粉圓（SIL OFL 1.1）。
- **顏色**：

| 名稱 | 色碼 | 用途 |
|---|---|---|
| 珊瑚紅 | `#FF5E5B` | 拍照、主要動作 |
| 向日葵黃 | `#FFC94A` | 今天、獎勵 |
| 天空藍 | `#4DA8FF` | 作品、相簿 |
| 草地綠 | `#6BCB77` | 完成、地圖 |
| 葡萄紫 | `#8C6CFF` | 復原、魔法 |
| 櫻花粉 | `#FF8FB1` | 貼紙、最愛 |
| 明信片米 | `#FFF8EC` | 背景 |
| 森林墨 | `#34413A` | 文字 |

- **按鈕**：主要按鈕 ≥ 76 dp，相機鈕 128 dp；下方有一條深色厚邊，看起來可以按。
- **插圖**：全部用向量自己畫（地圖、建築、角色、貼紙、工具），不再用表情符號圖庫，所以風格統一，也可以直接放進 APP（Flutter 用 SVG 或 CustomPainter）。
